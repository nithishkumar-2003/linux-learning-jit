Fetch the latest release info
wget -qO- https://api.github.com/repos/Itai-Nelken/BalenaEtcher-arm/releases/latest | grep "arm64.deb"

Download that exact file

Once you see something like:
"browser_download_url": "https://github.com/Itai-Nelken/BalenaEtcher-arm/releases/download/v1.7.9/balena-etcher-electron_1.7.9_arm64.deb"

then run:
wget https://github.com/Itai-Nelken/BalenaEtcher-arm/releases/download/v1.7.9/balena-etcher-electron_1.7.9_arm64.deb
(Replace v1.7.9 and the filename above with the version you found.)

Install it
sudo apt update
sudo apt install -y ./balena-etcher-electron_*_arm64.deb

Run balenaEtcher
balena-etcher-electron


sudo nano /usr/share/applications/balena-etcher-electron.desktop
replace
Exec=/opt/balenaEtcher/balena-etcher-electron --no-sandbox %U

sudo update-desktop-database

Optional (nice cleanup): add it to PATH

If you want balena-etcher-electron to work from terminal without typing the full path:
sudo ln -s /opt/balenaEtcher/balena-etcher-electron /usr/local/bin/balena-etcher-electron

(Adjust source path if needed.)
Then:
balena-etcher-electron --no-sandbox
